## Labs by Exam Domain

### Topic 01 — Enterprise Architecture (15%)

Design principles · wireless design · SD-WAN · SD-Access · QoS · switching mechanisms. Skills Framework K1, A1.

- **Lab 01** — [Investigate the CAM and TCAM Tables](lab-01-cam-tcam/README.md) — Describe hardware switching mechanisms such as CAM, TCAM, FIB, RIB and adjacency tables (ENCOR 1.6).
- **Lab 02** — [Analyse Cisco Express Forwarding](lab-02-cef/README.md) — Describe and verify CEF, the FIB and the adjacency table, and contrast them with process and fast switching (ENCOR 1.6).
- **Lab 03** — [Compare Two-Tier and Three-Tier Campus Designs](lab-03-campus-design/README.md) — Explain enterprise design principles including 2-tier, 3-tier, fabric and cloud designs (ENCOR 1.1.a).
- **Lab 04** — [Interpret Wired and Wireless QoS Configurations](lab-04-qos/README.md) — Interpret wired and wireless QoS configurations, including QoS components and QoS policy (ENCOR 1.5).
- **Lab 05** — [Explore SD-WAN and SD-Access Architecture](lab-05-sdwan-sdaccess/README.md) — Explain the working principles of the Cisco SD-WAN and SD-Access solutions and their control and data plane elements (ENCOR 1.3, 1.4).

### Topic 02 — Virtualization Technologies (10%)

Hypervisors · virtual machines · virtual switching · VRF · GRE and IPsec · LISP and VXLAN. Skills Framework K2, A2.

- **Lab 06** — [Configure and Verify VRF-Lite](lab-06-vrf-lite/README.md) — Configure and verify data path virtualization technologies — VRF (ENCOR 2.2.a).
- **Lab 07** — [Configure and Verify a GRE Tunnel](lab-07-gre/README.md) — Configure and verify data path virtualization technologies — GRE tunneling (ENCOR 2.2.b).
- **Lab 08** — [Configure and Verify a Site-to-Site IPsec VPN](lab-08-ipsec-vpn/README.md) — Configure and verify data path virtualization technologies — IPsec tunneling (ENCOR 2.2.b).
- **Lab 09** — [Explore LISP and VXLAN Network Virtualization](lab-09-lisp-vxlan/README.md) — Describe network virtualization concepts — LISP and VXLAN (ENCOR 2.3.a, 2.3.b).

### Topic 03 — Network Infrastructure (30%)

Layer 2 · Layer 3 routing · wireless · IP services — the largest exam domain. Skills Framework K3, A3.

- **Lab 10** — [Troubleshoot 802.1Q Trunking and DTP](lab-10-trunking-dtp/README.md) — Troubleshoot static and dynamic 802.1q trunking protocols (ENCOR 3.1.a).
- **Lab 11** — [Troubleshoot Static and Dynamic EtherChannels](lab-11-etherchannel/README.md) — Troubleshoot static and dynamic EtherChannels — PAgP and LACP (ENCOR 3.1.b).
- **Lab 12** — [Configure RSTP and Tune the Spanning Tree](lab-12-rstp/README.md) — Configure and verify common Spanning Tree Protocols — RSTP — and Spanning Tree enhancements (ENCOR 3.1.c).
- **Lab 13** — [Configure Multiple Spanning Tree (MST)](lab-13-mst/README.md) — Configure and verify common Spanning Tree Protocols — MST (ENCOR 3.1.c).
- **Lab 14** — [Harden the Spanning Tree with PortFast, BPDU Guard and Root Guard](lab-14-stp-hardening/README.md) — Configure and verify Spanning Tree enhancements such as root guard and BPDU guard (ENCOR 3.1.c).
- **Lab 15** — [Compare EIGRP and OSPF Path Selection](lab-15-eigrp-ospf/README.md) — Compare routing concepts of EIGRP and OSPF — advanced distance vector versus link state, load balancing, path selection, metrics and area types (ENCOR 3.2.a).
- **Lab 16** — [Configure Multiarea OSPFv2 with Summarization and Filtering](lab-16-ospf-multiarea/README.md) — Configure simple OSPFv2 environments including multiple normal areas, summarization and filtering (ENCOR 3.2.b).
- **Lab 17** — [Configure Multiarea OSPFv3 for IPv6](lab-17-ospfv3/README.md) — Configure simple OSPFv3 environments including multiple normal areas (ENCOR 3.2.b).
- **Lab 18** — [Configure and Verify eBGP](lab-18-ebgp/README.md) — Configure and verify eBGP between directly connected neighbours, including best path selection and neighbour relationships (ENCOR 3.2.c).
- **Lab 19** — [Configure a Basic WLAN and WPA2-Enterprise on the WLC](lab-19-wlc-wlan/README.md) — Describe AP discovery and join, wireless segmentation with groups, profiles and tags, and configure wireless security features (ENCOR 3.3.c, 3.3.f, 5.4).
- **Lab 20** — [Troubleshoot WLAN and Wireless Client Connectivity](lab-20-wlan-troubleshoot/README.md) — Troubleshoot WLAN configuration and wireless client connectivity issues using GUI only (ENCOR 3.3.e).
- **Lab 21** — [Configure NTP, NAT/PAT and HSRP](lab-21-ip-services/README.md) — Interpret NTP configurations, configure NAT/PAT, and configure first hop redundancy protocols such as HSRP and VRRP (ENCOR 3.4.a, 3.4.b, 3.4.c).

### Topic 04 — Network Assurance (10%)

Diagnostics · NetFlow · SPAN/RSPAN/ERSPAN · IP SLA · DNA Center · NETCONF and RESTCONF. Skills Framework K5, A4.

- **Lab 22** — [Diagnose Network Problems with Ping, Traceroute and Conditional Debug](lab-22-diagnostics/README.md) — Diagnose network problems using tools such as debugs, conditional debugs, traceroute, ping, SNMP and syslog (ENCOR 4.1).
- **Lab 23** — [Configure Syslog, SNMP and Flexible NetFlow](lab-23-netflow-syslog/README.md) — Configure and verify Flexible NetFlow, and use SNMP and syslog for diagnosis (ENCOR 4.1, 4.2).
- **Lab 24** — [Configure SPAN, RSPAN and IP SLA](lab-24-span-ipsla/README.md) — Configure SPAN/RSPAN/ERSPAN and configure and verify IPSLA (ENCOR 4.3, 4.4).
- **Lab 25** — [Configure NETCONF and RESTCONF and Explore DNA Center Workflows](lab-25-netconf-restconf/README.md) — Configure and verify NETCONF and RESTCONF, and describe Cisco DNA Center workflows (ENCOR 4.5, 4.6).

### Topic 05 — Network Security (20%)

Device access control · AAA · ACLs and CoPP · REST API security · wireless security · security design. Skills Framework K4, A6.

- **Lab 26** — [Configure Secure Device Access with SSH and Strong Passwords](lab-26-secure-access/README.md) — Configure and verify device access control — lines and local user authentication (ENCOR 5.1.a).
- **Lab 27** — [Implement Local and Server-Based AAA](lab-27-aaa/README.md) — Configure and verify device access control — authentication and authorization using AAA (ENCOR 5.1.b).
- **Lab 28** — [Configure Extended ACLs to Mitigate Attacks](lab-28-acls/README.md) — Configure and verify infrastructure security features — ACLs (ENCOR 5.2.a).
- **Lab 29** — [Configure Control Plane Policing](lab-29-copp/README.md) — Configure and verify infrastructure security features — CoPP (ENCOR 5.2.b).
- **Lab 30** — [Analyse Wireless Security, REST API Security and Security Design](lab-30-security-design/README.md) — Describe REST API security, configure wireless security features, and describe the components of network security design (ENCOR 5.3, 5.4, 5.5).

### Topic 06 — Network Automation (15%)

Python · JSON · YANG · DNA Center and vManage APIs · REST responses · EEM · orchestration tools. Skills Framework K6, A5.

- **Lab 31** — [Interpret Python Components and Scripts](lab-31-python/README.md) — Interpret basic Python components and scripts (ENCOR 6.1).
- **Lab 32** — [Construct and Validate JSON-Encoded Files](lab-32-json/README.md) — Construct valid JSON-encoded files (ENCOR 6.2).
- **Lab 33** — [Explore YANG Models and Call the DNA Center API](lab-33-yang-dnac/README.md) — Describe the principles and benefits of YANG, describe APIs for Cisco DNA Center and vManage, and interpret REST API response codes (ENCOR 6.3, 6.4, 6.5).
- **Lab 34** — [Construct an EEM Applet to Automate Response](lab-34-eem/README.md) — Construct an EEM applet to automate configuration, troubleshooting or data collection (ENCOR 6.6).
- **Lab 35** — [Compare Agent and Agentless Orchestration Tools](lab-35-orchestration/README.md) — Compare agent versus agentless orchestration tools such as Chef, Puppet, Ansible and SaltStack (ENCOR 6.7).
